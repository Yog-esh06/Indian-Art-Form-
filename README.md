## Technology

- **Core:** Vanilla HTML5, CSS3, and ES6 JavaScript
- **Layout and motion:** CSS Flexbox, Grid, responsive media queries and keyframe animation
- **Generative artwork:** HTML5 Canvas API
- **Interactive map:** [Leaflet](https://leafletjs.com/) with OpenStreetMap tiles
- **PDF export:** [jsPDF](https://parall.ax/products/jspdf)
- **Typography:** Playfair Display and DM Sans

## Project Structure

```text
Indian-Art-Form-/
├── index.html          # Main portal and navigation
├── index.css           # Portal layout, theme and typography
├── theme.js            # Shared, persistent light and dark mode
├── timeline.html       # Interactive historical timeline
├── timeline.css        # Timeline presentation and modal styling
├── timeline.js         # Artifact content and timeline interactions
├── map.html            # Regional Indian art map
├── map.css             # Map, markers, panels and theme styling
├── map.js              # Leaflet layers and regional navigation
├── fusion.html         # Generative painting studio
├── fusion.css          # Studio layout and theme styling
├── fusion.js           # Canvas artwork and PDF collage export
└── README.md           # Project overview
```

The pages are independent static HTML documents and use relative links to navigate between the portal, timeline, map and studio. External fonts, map tiles, images, Leaflet and jsPDF require an internet connection.
