## 🛠️ Technology

* **Core:** Vanilla HTML5, CSS3, ES6 JavaScript
* **Layout and Motion:** CSS Flexbox, Grid, CSS Variables, Responsive Media Queries, Keyframe Animations
* **Generative Artwork:** HTML5 Canvas API
* **Interactive Map:** [Leaflet](https://leafletjs.com/) with OpenStreetMap tiles
* **PDF Export:** [jsPDF](https://parall.ax/products/jspdf)
* **Typography:** Playfair Display, DM Sans

## 🚀 How to Clone and Run Instructions

1. **Clone the Repository:** Terminal / Command Line.
Run the following git command to clone the repository onto your local machine:

```bash
git clone [https://github.com/yog-esh06/Indian-Art-Form-.git](https://github.com/yog-esh06/Indian-Art-Form-.git)

```


2. **Navigate into the Directory:**
Change your current directory to the cloned project folder:

```bash
cd Indian-Art-Form-

```


3. **Launch the Application:**
Since the application is built using vanilla HTML, CSS, and JS, you can open it directly in your browser:

* **Option A (Direct File Launch):**
* **Windows:** `start index.html`
* **macOS:** `open index.html`
* **Linux:** `xdg-open index.html`


* **Option B (Local Web Server - Recommended):**
Run a local server using Python to serve the static assets seamlessly:

```bash
python -m http.server 8000

```

Then open `http://localhost:8000` in your web browser.
